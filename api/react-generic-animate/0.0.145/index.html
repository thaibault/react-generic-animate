react-generic-animate 0.0.145

Project Status

Use case

A React component which fades its content in when it appears and out before it disappears. Wrap anything that is shown conditionally, like hints, error messages or list entries, and it no longer pops in and out abruptly. It is a thin, preconfigured layer on top of "CSSTransition" from react-transition-group.

Features included:

  • Fade animation of 200 milliseconds on mount, on "in" changes and before unmount.
  • Removes the content from the DOM once it is faded out.
  • Wraps text and single elements in a "span" and lists in a "div".
  • Accepts all "CSSTransition" properties, e.g. for own animations.

Content

Installation

Install the package together with its peer dependencies:

npm install \
    react-generic-animate \
    clientnode core-js prop-types react react-dom react-transition-group

Include the stylesheet once, either in your CSS or in your JavaScript entry module:

@import "react-generic-animate/index.css";

Example

Two texts which take turns every two seconds:

import {useEffect, useState} from 'react'
import GenericAnimate from 'react-generic-animate'

export const Application = () => {
    const [visible, setVisible] = useState(false)

    useEffect(() => {
        const interval = setInterval(
            () => {
                setVisible((value) => !value)
            },
            2000
        )

        return () => {
            clearInterval(interval)
        }
    }, [])

    return <>
        <GenericAnimate in={visible}>Now you see me.</GenericAnimate>
        <GenericAnimate in={!visible}>Now you see me instead.</GenericAnimate>
    </>
}

Properties

All properties are passed to "CSSTransition". The most important ones:

  • "in": Shows the content if "true" (default), hides it if "false".
  • "timeout": Duration in milliseconds until a transition is finished. Defaults to "200" which matches the included stylesheet.
  • "appear": Animates on first mount as well. Defaults to "true".
  • "unmountOnExit": Removes the content after it is hidden. Defaults to "true".
  • "classNames": Class name prefix for the transition states. Defaults to "generic-animate".
  • "onEnter", "onEntered", "onExit", "onExited" and similar: Callbacks for the transition phases.

Custom animations

Give another class name prefix and define the transition states in your CSS:

<GenericAnimate classNames="slide" in={open} timeout={300}>
    <Menu />
</GenericAnimate>

.slide-appear, .slide-enter {transform: translateY(-1em); opacity: 0}
.slide-appear-active, .slide-enter-active {
    transform: none;
    opacity: 1;
    transition: all 300ms ease-out;
}
.slide-exit {opacity: 1}
.slide-exit-active {opacity: 0; transition: opacity 300ms ease-in}
